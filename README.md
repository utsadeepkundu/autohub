# AutoHub — Find Your Drive

AutoHub is a car discovery and dealer marketplace application for the Indian market. It combines a React/Vite frontend with a Django REST Framework backend and MongoDB.

## Features

- **New cars:** Browse manufacturers and models, open model details, inspect gallery/specifications, and view available variants and catalogue prices.
- **Used cars:** Search imported used-car listings, refine results by make/model/location/specifications/price/year/odometer/ownership, sort and paginate, and open listing details.
- **Compare:** Compare two or three new-car variants using the catalogue API, including available specifications, features and comparable pricing.
- **Price valuation:** Request an indicative used-car market estimate based on available catalogue listings. Signed-in users can view their own saved valuation history.
- **Customer accounts:** Register and sign in with email/password. JWT access/refresh tokens are stored in the browser session and refreshed by the API client.
- **Dealer workspace:** Apply for dealer verification, manage inventory after approval, submit listings for review and manage customer enquiries.
- **Dealer marketplace:** Browse published listings from approved dealers and submit an enquiry directly to a dealer.

## Technology

- Frontend: React 19, React Router, Vite 8, Lucide icons and custom responsive CSS.
- Backend: Django 6.1, Django REST Framework, django-mongodb-backend, Simple JWT, django-filter and django-cors-headers.
- Database: MongoDB Atlas.
- Optional local cache: Redis. Local development can use Django's in-memory cache; production settings require a shared Redis URL.

## Important operational notes

1. **Do not commit `.env` or `.env.local` files.** The ZIP intentionally contains templates only. Create your own local environment files and enter your own MongoDB URI and Django secret key.
2. Dealer applications and dealer vehicle listings require administrator review. A dealer must be approved before creating listings; each new/edited listing must be published by an administrator before it appears in the public dealer marketplace.
3. The imported used-car marketplace is a catalogue of external listings. AutoHub does not independently verify the seller, vehicle condition, price, availability or the external source's right to redistribute the listing data. Review data-provider terms/licensing and show appropriate attribution before public commercial launch.
4. On-road vehicle pricing is shown only where the catalogue contains pricing for the relevant city. Do not assume a price is available for every city or variant.
5. The local ZIP is a source-code handoff, not a production deployment. Production requires a deployed Django API, managed MongoDB/Redis, correct CORS/allowed-host settings, SMTP, HTTPS, domain configuration and provider/data licensing review.

## Production build

Frontend production output is generated by `npm run build` in `frontend/`. Deploy the generated `frontend/dist/` folder using Vercel or another static hosting provider. Deploy the Django backend separately on a Python application host; point `VITE_API_BASE_URL` to its HTTPS API base before building the frontend for production.
